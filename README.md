## 关于 SeisY

SeisY 是一个面向地震、月震与行星地震数据处理、分析与可视化的桌面软件平台。

它集成了多种专业工具，包括但不限于：

- 波形数据处理
- 频谱分析
- 震源定位
- 射线追踪
- 简正模分析
- 月震 / Apollo 数据流程

## 下载方式

# SEISY-Releases

This is the official public release repository for **SeisY**.

It provides downloadable release assets for end users, including Windows installers and portable builds, while the main development workflow may be maintained separately.

- Windows installer packages
- Portable builds
- Versioned release notes

## About SeisY

SeisY is a desktop platform for seismic, lunar seismic, and planetary seismic data processing, analysis, and visualization.

It integrates tools for:

- waveform processing
- spectral analysis
- hypocenter location
- ray tracing
- normal mode analysis
- lunar/Apollo data workflows

## Download

Please go to the [Releases](../../releases) page to download the latest version.

Typical assets include:

- `SeisY-x.x.x-Setup.exe` — recommended installer for most users
- `SeisY-x.x.x-Portable.zip` — portable version, unzip and run `SeisY.exe`
